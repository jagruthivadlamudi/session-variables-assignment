LOGIN AND REGISTRATION ASSIGNMENT

1. Open this folder in VS Code.
2. In a terminal run: npm install
3. Make sure MySQL is running. Run setup.sql in MySQL to create the paws database and users table.
4. Set your MySQL root password as ROOTPASS (or use a dedicated database user and update server.js).
   macOS example: export ROOTPASS='your_mysql_password'
5. Run: npm start
6. Visit http://localhost:3000/register.html
7. Register a test user, then log in with the same credentials. Also test an incorrect password.
